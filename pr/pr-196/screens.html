Screens

Seven archive.org pages composed from the components and nothing else, covering the page shells in docs/patterns/page-shells.md. The content is real, read from the reference pages. Each screen responds to its own width, so the preview switch shows the 375px layout.

They are drawn with the reference CSS from the Specs tab, not with the elements. As elements match their specs, the screens switch to the real thing, starting with the topnav, buttons and search bar.
